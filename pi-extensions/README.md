# pi-extensions

Extensions for [pi](https://github.com/earendil-works/pi), a terminal coding agent. Each
subfolder is one self-contained extension: drop the folder into `~/.pi/agent/extensions/`
and pi discovers it on the next start.

## Contents

- **[copy-table](copy-table/README.md)** — copy any markdown table out of the conversation
  as TSV, ready to paste into a spreadsheet. Tables get short AI-generated names so the
  picker reads like a list of tables rather than `Table 1, Table 2`.
